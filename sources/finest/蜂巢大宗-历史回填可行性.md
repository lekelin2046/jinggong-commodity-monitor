## 二、逐源实测证据

### 1️⃣ 长江有色网 ccmn — ❌ 不可用（本次实测证伪旧记录）

`POST /shop/historyData/getCorpStmarketPriceList` 带 `publishDate` 参数**不生效**：

| 请求 publishDate | 响应体 `publishDate` | 1#铜 | 1#白银 |
|---|---|---|---|
| 2026-10-15 | 2026-10-15 | 110,670~110,710 | 13,625 |
| **2020-10-15** | **2026-10-15** | 110,670~110,710 | 13,625 |
| **2015-06-01** | **2026-10-15** | 110,670~110,710 | 13,625 |

→ 三次请求返回**同一份当日数据**，参数被忽略。会员历史接口 `POST /metalquote/query` 返回 `400 系统内部异常`。

> ⚠️ **SKILL.md 需修正**：附录「历史回溯限制」写「ccmn AJAX 可按 `publishDate` 回溯历史（已支持）」—— 与 2026-09-17 `fetcher_ccmn.py` 的注释及本次实测**均矛盾**，属过时结论。
> 实际：ccmn 历史需**会员登录**，故蜂巢 CU / AG 的历史只能走「复用现有看板」路线。

### 2️⃣ SMM 上海有色 — ⚠️ 历史在付费专站

- 历史价站确实存在：`https://price.smm.cn/spot_price`（「历史价格」功能，品目含「SMM 1#电解铜」「SMM广东1#电解铜」，日期列表连续：10-15 / 10-14 / 10-13 / 10-12 / 10-09 …）
- 数据接口：`https://platform.smm.cn/spotcenter/v31/settlement/history/prices?token=<JWT>`
- 但项目既有结论（`bridge_jinggong.py` docstring）明确：**「SMM 铝的历史在源站是付费内容」** → 我方账号无该权限，故不作回填来源。
- 🔴 **探测副作用（已排查）**：探测中 `price.smm.cn` 返回「您的账号已在其他设备登陆」。
  已立即回归验证生产通道 `hq.smm.cn`：**14 项全部正常抓到**（含 CU_CATH1=110,485），未受影响。
  推测为历史站与本账号存在单点登录冲突。**后续不宜反复登录该站**。

### 3️⃣ 卓创资讯 sci99 — ⚠️ 历史功能需登录态（当日价正常）

`prices.sci99.com` 搜索页确有「**查看并下载历史数据**」「**查看对比曲线**」控件，历史能力存在。
但实测其曲线接口：

```
POST https://prices.sci99.com/selectedlines/getlines.ashx
→ {"status":200,"msg":"success","isLogin":"0","data":[]}
```

`isLogin:0` → 当前 cookie（`cookies/sci99.json`，文件时间 2026-07-21）在**历史接口**上未通过登录。
而**当日价通道正常**：2026-10-15 蜂巢 PA6 / PA66 均成功抓到（15,100 / 19,000）。

→ 结论：PA6 / PA66 **当日价可抓、历史暂不可回填**；待恢复登录态后再评估。

### 4️⃣ 亚洲金属网 — ✅ **本次新发现**：曲线接口可回溯 12 个月

页面 `/PraseodymiumPriceIndex`（镨价格走势）**内联 echarts 走势图**，时间选择器为 **1个月 / 3个月 / 12个月**。
数据接口（实测有效）：

```
POST https://www.asianmetal.cn/price/priceChartExpectation.am
body: ppId=<价格参数ID>&chartDate=<1|2|4>        # 1=1个月 2=3个月 4=12个月
→ 返回 JS 数组 chartList，元素含 PDate / PLNum(低) / PHNum(高) / PNum(中间)
```

实测（镨钕混合金属 Pr25/Nd75 中国出厂，**ppId=526**）：

| chartDate | 点数 | 起 | 止 |
|---|---|---|---|
| 1（1 个月） | 23 | 2026-09-15 | 2026-10-22 |
| 2（3 个月） | 67 | 2026-07-15 | 2026-10-22 |
| **4（12 个月）** | **250** | **2025-10-15** | 2026-10-22 |

**三个品种的 ppId 已定位**（口径与蜂巢现用完全一致：中国出厂 + 人民币）：

| 品种 | ppId | 品名 / 规格 / 单位 |
|---|---|---|
| PRND | **526** | 镨钕混合金属 Pr 25%, Nd 75% 中国出厂 元/吨 |
| DYFE | **504** | 镝铁 80% 中国出厂 元/公斤 |
| TB | **532** | 金属铽 99.9%min 中国出厂 元/公斤 |

⚠️ **两个必须注意的坑**：
1. **尾部含预测值** —— 序列末端到 **2026-10-22**（未来日期），因该接口名为 `Expectation`，series 含「7/14/28 天预测价格」。回填时**必须截断至当日**，否则会把预测值当历史写入。
2. **取值字段** —— `PNum`（中间值）与 `(PLNum+PHNum)/2` 实测相等（884,500 = (882,000+887,000)/2），与现用取法一致；但尾部预测行 `PLNum/PHNum` 为 `null`，只能靠 `PDate` 过滤，不能靠字段空值判断。

> 💡 该接口**不限稀土**，镁锭（精工/曼德在用）应同样适用，可作后续精工历史回填的备选通道。

## 四、附：回填应有的安全闸门（照 `backfill_mand.py` 范式）

- **只补空缺，绝不覆盖**：与已有值冲突时保留原值 + 告警待人工核对
- **口径闸门**：与独立基准重叠区一致率 ≥95% 才执行，不达标拒绝落盘
- **只写交易日**：周末 / 法定节假日跳过
- **不新增日期列**：只写日期底盘内已存在的日期
- **截断未来日期**（稀土曲线特有）
- **离群点跳过**：与相邻 ±10 点中位数偏离 >50% 判为录入错误
- **落盘前自动备份**，跑完核对 `git rev-list` 为 `0 0`
