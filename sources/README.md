### ⚠️ 为什么主共享表不在本目录

`2026年有色金属市场价格.xlsx` **保留在仓库根目录**，原因有两条，均为硬约束：

1. **被 8 处路径常量引用**，写法统一为 `SCRIPT_DIR / "2026年有色金属市场价格.xlsx"`：
   `daily_update_all.py`、`daily_check_missed.py`、`backfill_lme_official.py`、`export_excel_to_json.py`、
   `sync_from_web.py`、`manual_fill_tungsten.py`、`refetch_wenxi_now.py`、`backfill_tungsten_from_article.py`（后者为 cwd 相对路径）。
2. **由 4 个定时任务读写**（15:00 全品种 / 17:00 补抓 / 9:00 LME 回填 / 手动钨粉回填），
   移动会牵动无人值守流程，而抓不到的数据**无法事后补齐**。

2026-09-23 整理已把它的 **11 个 `.bak-*` 备份移入 `backups/精工/`**，
根目录现在只剩它一个 `.xlsx`，可找性已解决。

> 如仍需将其归入本目录，须同步改上述 8 处常量并做端到端验证。**动手前请先与主人确认。**
